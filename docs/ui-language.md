# LG Nexus – UI-Sprache

## Grundregel

Die sichtbare Nexus-Oberfläche soll wie ein eigenständiges Stadtsystem wirken und keine Meta-Begriffe verwenden.

Nicht in der Benutzeroberfläche verwenden:

- RP
- IC
- OOC
- Roleplay
- ähnliche Meta-Bezeichnungen

Stattdessen immer neutrale Begriffe verwenden, zum Beispiel:

- `Geburtsdatum` statt `RP-Geburtsdatum`
- `Name` oder `Bürgername` statt Meta-Bezeichnungen für Charakternamen
- `Bürger`, `Mitarbeiter`, `Organisation`, `Behörde`, `Dienst`, `Einsatz`, `Akte`, `Vorgang`
- normale Formulierungen wie `Abende`, `Veranstaltungen`, `Stadtleben` statt `RP-Abende`

Diese Regel gilt für Labels, Formulare, Hilfetexte, Demo-Inhalte, Fehlermeldungen, Benachrichtigungen und sonstige Texte, die Nutzer sehen.
